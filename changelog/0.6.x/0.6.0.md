# 0.6.0 — 2026-10-18

## Changed

- **`aviation_get_advisories`** serves international SIGMETs and Center Weather Advisories through `isigmet` and `cwa`; default `all` reads all three independent products, preserving healthy results when another source fails ([#42](https://github.com/cyanheads/aviation-weather-mcp-server/issues/42)).
- **Advisory output (breaking)**: `series_id`, `issued_by`, `hazard`, `valid_from`, `valid_to`, `raw_text` and `polygon` can be null when source data is missing; `polygon` is also null for multipart or line geometry. Consumers must handle nulls.
- **Advisory geometry and provenance** preserve separate rings/lines, source/FIR/qualifier fields and international direction text; bbox checks include every part and date-line crossings.
- **Advisory coverage** reports source failures and skipped rows through `coverage`/`partial`; bbox results disclose `drawn`, `matched`, `returned` and `unlocated`, including exclusions when matches survive ([#49](https://github.com/cyanheads/aviation-weather-mcp-server/issues/49)).
- **Advisory `limit`** optionally bounds returned matches with stable ordering, totals and retrieval guidance; omitting it returns every available match.
- **`aviation_preflight_brief`** includes all three advisory products and names partial coverage, unlocated geometry and limited results as assessment gaps.

## Fixed

- **Station IDs** accept four ASCII letters or digits in either case across METAR, TAF, PIREP and preflight arguments; requests and reconciliation use uppercase, and malformed IDs receive station-discovery guidance ([#55](https://github.com/cyanheads/aviation-weather-mcp-server/issues/55)).
- **Advisory bulletins** render in dynamically sized code fences, preserving multiline text, blank lines and embedded backticks ([#40](https://github.com/cyanheads/aviation-weather-mcp-server/issues/40)).
