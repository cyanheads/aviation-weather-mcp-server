# 0.1.7 — 2026-07-11

## Fixed

- **`aviation_find_stations` conflicting location** — supplying `station_ids` together with `bbox` or `state` now throws a `conflicting_location` validation error instead of silently ignoring the location filter, mirroring the guard `aviation_get_pireps` already uses for `station_id` + `bbox`. [#9](https://github.com/cyanheads/aviation-weather-mcp-server/issues/9)
- **README / `docs/design.md`** — corrected the `aviation_find_stations` lookup claim from "ICAO, IATA, or FAA ID" to ICAO-only; returned records still include IATA/FAA aliases when available. [#8](https://github.com/cyanheads/aviation-weather-mcp-server/issues/8)
