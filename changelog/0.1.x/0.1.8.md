# 0.1.8 — 2026-07-11

## Changed

- **`aviation_preflight_brief` TAF step** — now calls `aviation_get_taf` for the same normalized ICAO list the METAR step uses (departure + destination + alternates), instead of departure/destination only. [#7](https://github.com/cyanheads/aviation-weather-mcp-server/issues/7)

## Fixed

- **`aviation_find_stations` conflicting location** — the `conflicting_location` guard now rejects whenever more than one of `station_ids`, `bbox`, or `state` is provided; previously `bbox` + `state` (with `station_ids` omitted) silently dropped `state` and searched by `bbox` alone. [#10](https://github.com/cyanheads/aviation-weather-mcp-server/issues/10)
