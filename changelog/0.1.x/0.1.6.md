# 0.1.6 — 2026-07-11

## Fixed

- **`aviation_find_stations` / `aviation_get_metar` elevation** — `elevation_ft` now converts the upstream AWC `elev` field (meters) to feet via a new `metersToFeet` helper, instead of passing the raw meters value through unconverted. [#4](https://github.com/cyanheads/aviation-weather-mcp-server/issues/4)
- **`aviation_get_pireps` conflicting location** — providing both `station_id` and `bbox` now throws a `conflicting_location` validation error instead of silently ignoring `bbox` and running a radial search. [#5](https://github.com/cyanheads/aviation-weather-mcp-server/issues/5)
- **Inverted bounding boxes** — `aviation_get_pireps`, `aviation_find_stations`, and `aviation_get_advisories` now reject `bbox` inputs where `minLat > maxLat` or `minLon > maxLon` with an `invalid_bbox` validation error, instead of returning misleading empty/not-found results. Adds a shared `isBboxOrdered` predicate in `src/services/aviation-weather/bbox.ts`. [#6](https://github.com/cyanheads/aviation-weather-mcp-server/issues/6)

## Changed

- **Supply-chain hardening** — `bunfig.toml` blocks installing package versions published less than 3 days ago (`minimumReleaseAge`, with `@cyanheads/mcp-ts-core` excluded for same-day framework adoption) and scans installs with the new `@socketsecurity/bun-security-scanner` devDependency; `Dockerfile` build-stage install now runs with `--ignore-scripts` and BuildKit cache mounts, pinned to `oven/bun:1.3.14`.
- **Vendored skills + scripts** — `skills/` and the `scripts/` devcheck toolchain resynced to the `@cyanheads/mcp-ts-core` `0.10.14` set.
