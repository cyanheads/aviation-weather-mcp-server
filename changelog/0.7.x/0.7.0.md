# 0.7.0 — 2026-10-31

## Added

- Publish aviation-weather-guide as an MCP skill resource for regional surveys, airport comparisons, and route assessments.
- **`aviation_get_advisories.altitude_ft`** selects a ±3,000 ft cruise band, discloses source filtering and unknown bounds, and receives explicitly supplied cruise altitude from `aviation_preflight_brief` ([#72](https://github.com/cyanheads/aviation-weather-mcp-server/issues/72)).
- **Advisory provenance and movement** expose international tendency, CWA office names and evidence-based international stationarity alongside source direction and speed ([#73](https://github.com/cyanheads/aviation-weather-mcp-server/issues/73)).

## Changed

- **Plugin and bundle delivery** add Agent Plugins manifests, include the published guide in npm/Docker/MCPB, and preserve SDK runtime skills modules while stripping development-only bundle content.
- **Development checks** validate published skills and plugin packaging; framework documentation and bug-report environment fields follow the adopted framework.

## Fixed

- **Domestic SIGMET altitudes** recover alternate bounds when finite primary values are unavailable; severity remains a source-native value ([#58](https://github.com/cyanheads/aviation-weather-mcp-server/issues/58)).
- **Thunderstorm selection** treats `TS` and `CONVECTIVE` as aliases across domestic/international SIGMETs and CWAs ([#60](https://github.com/cyanheads/aviation-weather-mcp-server/issues/60)).
- **Date-line geometry** normalizes extended source longitudes so intact multipart SIGMETs participate in geographic matching ([#63](https://github.com/cyanheads/aviation-weather-mcp-server/issues/63)).
- **CWA cancellations** are excluded before active counts and disclosed separately through `coverage[].cancelled` ([#64](https://github.com/cyanheads/aviation-weather-mcp-server/issues/64)).
