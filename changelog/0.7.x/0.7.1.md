# 0.7.1 — 2026-10-31

## Added

- **`aviation_find_stations.magnetic_declination`** supplies signed degrees and exact published airport variation text for named stations; unavailable supplementary data leaves station results valid with a notice. [#74](https://github.com/cyanheads/aviation-weather-mcp-server/issues/74)
- **`aviation_get_pireps.braking_action`** preserves decoded AWC braking codes without inferring runway conditions. [#65](https://github.com/cyanheads/aviation-weather-mcp-server/issues/65)

## Fixed

- **`aviation_get_pireps.distance_nm`** selects a nautical-mile circle, including antimeridian searches, with cap disclosure before local filtering; unavailable center coordinates retain the legacy search with an unverified-radius notice. [#59](https://github.com/cyanheads/aviation-weather-mcp-server/issues/59)
- **`aviation_find_stations.state`** selects every US registry member assigned to the state from a validated snapshot fresh for 24 hours, including offshore and eastern-longitude Alaska stations. [#61](https://github.com/cyanheads/aviation-weather-mcp-server/issues/61)
- **`aviation_find_stations.station_ids`** splits commas and trims tokens before querying and reconciliation, preserving first-spelling disclosures and the expanded twenty-identifier bound. [#62](https://github.com/cyanheads/aviation-weather-mcp-server/issues/62)
- **Urgent PIREP winds** carry the magnetic reference label; source report types remain open strings.
