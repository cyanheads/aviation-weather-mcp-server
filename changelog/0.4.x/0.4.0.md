# 0.4.0 — 2026-08-13

## Fixed

- **Breaking: AIRMET requests rejected, not answered as SIGMETs** — `aviation_get_advisories` throws `airmet_not_served` for `advisory_type: "airmet"` and the `MTN OBSCN`/`SURFACE WIND`/`LLWS` hazards; `/airsigmet` has no type filter and never served AIRMETs. [#12](https://github.com/cyanheads/aviation-weather-mcp-server/issues/12)
- **Truncation disclosure for capped results** — `aviation_find_stations` and `aviation_get_pireps` report `truncated`/`shown`/`cap`/`upstreamRows`/`notice` via `enrichment` when AWC's 400-row cap cuts a page; `no_pireps_found` no longer reports a capped page's row count as the area's total. [#11](https://github.com/cyanheads/aviation-weather-mcp-server/issues/11)
