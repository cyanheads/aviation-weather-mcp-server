# 0.4.2 — 2026-09-09

## Added

- **`min_intensity`** input on `aviation_get_pireps` — restricts results to reports carrying a turbulence or icing layer at `lgt`/`mod`/`sev` or above, sent upstream as `inten`. Selects reports, not layers: a matching report still carries its lighter layers. [#32](https://github.com/cyanheads/aviation-weather-mcp-server/issues/32)

## Changed

- **`aviation_get_pireps` altitude bounds are pushed upstream** as a `level` centre when the requested band is 6,000 ft wide or narrower, matching AWC's fixed ±3,000 ft search width — narrowing the page the 400-row cap applies to instead of only trimming it afterward. A wider band, a single bound, or neither behaves exactly as before. [#32](https://github.com/cyanheads/aviation-weather-mcp-server/issues/32)
- **Repo tooling adopts the 0.12.8 template** — `devcheck.ts`'s outdated check resolves `npm:` aliases and dev/peer/optional dependency groups before matching ranges; `lint-packaging.ts` now gates each plugin manifest's `version` against `package.json`'s; `check-framework-antipatterns.ts` allows `deferInputValidation()` as a sanctioned `.passthrough()` substitute.
- **Vendored agent skills re-synced to the 0.12.8 set** — `git-wrapup` 1.13, `release-and-publish` 2.14, `release-pr-review` (new), and 21 others.

## Fixed

- **`altitude_ft` no longer reports 0 for a malformed flight-level group.** The discriminator now reads whether the raw `/FL…/` group round-trips to the value AWC produced, rather than matching a fixed token list — the corpus contained call signs, station identifiers, and transpositions the enumerated set never covered. `/FLSFC/` and a genuine `/FL000/` are unaffected. [#25](https://github.com/cyanheads/aviation-weather-mcp-server/issues/25)
- **`icing[].intensity` no longer surfaces AWC's fabricated `NEGclr` layers.** A layer whose intensity carries a concatenated type suffix is dropped rather than published with altitude bounds borrowed from elsewhere in the same record. The test runs per layer, so a genuine first layer alongside a fabricated second one keeps only the genuine one. [#26](https://github.com/cyanheads/aviation-weather-mcp-server/issues/26)
