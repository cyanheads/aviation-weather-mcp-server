# 0.4.3 — 2026-09-09

## Added

- **`sky_condition`** on `aviation_get_metar` and `aviation_get_taf` — the reported or forecast condition (`CLR`/`SKC`/`CAVOK` for a clear or insignificant-cloud report, `OVX` for an obscuration with no determinable height) when there are no layer heights to publish; null when `clouds` carries layers or when nothing was reported at all. An empty `clouds` array is no longer treated as a clear sky on its own. [#27](https://github.com/cyanheads/aviation-weather-mcp-server/issues/27)
- **`requested`/`returned`/`partial`/`missing`** enrichment fields on `aviation_find_stations` — a batch lookup now discloses which requested identifiers resolved to nothing, splitting guidance between a non-ICAO-format identifier and an ICAO-shaped one absent from the AWC registry. Reconciliation matches the identifiers upstream returned, so a repeated or differently-cased ID is never reported as a gap. [#31](https://github.com/cyanheads/aviation-weather-mcp-server/issues/31)

## Changed

- **`hours` on `aviation_get_metar`** — the description previously stated the default returns only the most recent observation; it is a lookback window, and every observation inside it is returned, so a half-hourly station yields more than one row at the default of 1.
- **`visibility_sm` renders "not reported"** instead of "unknown sm" when the observation carried no visibility group.
- **`change_type` on `aviation_get_taf`** now documents `PROB` as a standalone value for a probability group with no accompanying `TEMPO`.

## Fixed

- **`aviation_get_metar`: an obscuration with no vertical visibility (a `VV///` group) no longer reads as no ceiling.** `sky_condition: 'OVX'` marks the case, and the ceiling line now renders "not determinable — sky obscured, no vertical visibility reported" instead of "none". [#27](https://github.com/cyanheads/aviation-weather-mcp-server/issues/27)
