# 0.4.4 — 2026-09-09

## Added

- **`notice`** enrichment field on `aviation_get_advisories` — populated on an empty result, naming the stage that produced it: no domestic SIGMETs active anywhere, none carrying the requested hazard, or none intersecting the requested bbox. [#33](https://github.com/cyanheads/aviation-weather-mcp-server/issues/33)

## Fixed

- **`aviation_get_advisories`: the `hazard` filter now matches upstream instead of a client-side substring test against an undocumented AWC vocabulary.** `CONVECTIVE`/`TURBULENCE`/`ICING`/`IFR` map to AWC's own `conv`/`turb`/`ice`/`ifr` `hazard` parameter, removing a comparison that could never match a shorter upstream token against a longer requested one. [#30](https://github.com/cyanheads/aviation-weather-mcp-server/issues/30)
