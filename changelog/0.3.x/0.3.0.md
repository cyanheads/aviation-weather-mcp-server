# 0.3.0 — 2026-08-13

## Added

- **Forecast wind shear** — `aviation_get_taf` forecast periods carry a new nullable `wind_shear` field (`height_ft`, `direction_deg`, `speed_kt`) decoded from the `WS` group; null means no non-convective LLWS group was issued, not that none is forecast. [#23](https://github.com/cyanheads/aviation-weather-mcp-server/issues/23)

## Fixed

- **Breaking: multi-group present weather** — `decodeWxString` now decodes each space-delimited weather group on its own instead of reading the whole value as one code; `aviation_get_taf` `forecast_periods[].weather` moves from `string | null` to `{ raw, decoded }`, matching `aviation_get_metar`. [#21](https://github.com/cyanheads/aviation-weather-mcp-server/issues/21)
- **Forecast obscuration** — `aviation_get_taf` no longer drops a forecast `OVX` layer or renders it as `Clear`; a new `vertical_visibility_ft` field carries the height in feet AGL, filled from the period's `vertVis`. [#28](https://github.com/cyanheads/aviation-weather-mcp-server/issues/28)
- **Partial-batch disclosure** — `aviation_get_metar` and `aviation_get_taf` report `requested`/`returned`/`partial`/`missing` via `enrichment`, so a station that returned nothing no longer vanishes from a batch result without a trace. [#18](https://github.com/cyanheads/aviation-weather-mcp-server/issues/18)
- **FAA AIM citation** — the METAR/TAF ceiling rule referenced AIM 7-1-13 (Runway Visual Range); corrected to 7-1-29.
