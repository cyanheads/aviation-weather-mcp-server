# 0.5.0 — 2026-09-24

## Added

- **`aviation_get_pireps` `temp_c` and `wind`** — outside air temperature (°C) and wind aloft (`{ direction_deg, speed_kt }`) as AWC decodes them from a PIREP's `/TA` and `/WV` or an AIREP's own groups; `content[]` renders them on one line. A PIREP `/WV` direction is magnetic and is published unconverted. [#41](https://github.com/cyanheads/aviation-weather-mcp-server/issues/41)
- **`aviation_get_metar` `flight_category`** (bbox only) — keeps the surveyed stations in the named categories (e.g. `["IFR", "LIFR"]`), judged on each station's latest observation and applied before `limit`; the new `surveyed` field counts stations before the filter, and a survey the filter empties returns an empty result with a notice. Rejected alongside `station_ids` as `conflicting_flight_category`. [#51](https://github.com/cyanheads/aviation-weather-mcp-server/issues/51)
- **Size notice on large results that set no `limit`** — past 50 reports (`aviation_get_pireps`), 40 stations (`aviation_get_metar` bbox), or 130 stations (`aviation_find_stations` bbox/state), `notice` names `limit` and what it keeps. Omitting `limit` still returns every match. [#46](https://github.com/cyanheads/aviation-weather-mcp-server/issues/46)

## Changed

- **`aviation_get_pireps` `remarks` renamed to `weather`, now a `{ raw, decoded }` pair** — the value never held `/RM` remarks, only the `/WX` group. Migration: `remarks` is gone and its value is now `weather.raw`; a consumer still reading `remarks` gets nothing, silently. `content[]` renders `**Weather:**` in place of `**Remarks:**`. [#41](https://github.com/cyanheads/aviation-weather-mcp-server/issues/41)

## Fixed

- **Cap guidance, empty-result hints, and notices name only levers the call can use** — no `distance_nm` on a PIREP `bbox` search, no smaller `bbox` on a `station_id` search, no shorter `hours` at 1 or longer at 12; `aviation_find_stations`' `station_not_found` hint is branched by search mode. [#53](https://github.com/cyanheads/aviation-weather-mcp-server/issues/53)
- **`aviation_get_pireps` `SKC` and `CLR` cloud layers publish `base_ft` and `top_ft` as null** — an `SKC` layer no longer carries AWC's synthesized base and 60,000 ft top; a real layer beneath it keeps its bounds. [#52](https://github.com/cyanheads/aviation-weather-mcp-server/issues/52)
