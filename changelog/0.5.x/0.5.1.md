# 0.5.1 — 2026-10-08

## Changed

- **`@cyanheads/mcp-ts-core` ^0.13.6 → ^0.13.14** — tool error results carry `data.requestId` and `content[]` closes with `request <id>` (0.13.10, [cyanheads/mcp-ts-core#576](https://github.com/cyanheads/mcp-ts-core/issues/576)). An integer sent for a string argument (0.13.9, [cyanheads/mcp-ts-core#487](https://github.com/cyanheads/mcp-ts-core/issues/487)) and a numeric string sent for a number argument (0.13.14, [cyanheads/mcp-ts-core#707](https://github.com/cyanheads/mcp-ts-core/issues/707)) are repaired instead of rejected. Stack traces, request context, and `rootCause` no longer reach client error data (0.13.7 [cyanheads/mcp-ts-core#519](https://github.com/cyanheads/mcp-ts-core/issues/519), 0.13.8 [cyanheads/mcp-ts-core#548](https://github.com/cyanheads/mcp-ts-core/issues/548), 0.13.13 [cyanheads/mcp-ts-core#644](https://github.com/cyanheads/mcp-ts-core/issues/644)).
- **Docker image installs production dependencies in a `deps` stage on the build platform** — the multi-arch build no longer runs Bun under QEMU, and musl-only packages are pruned from the image (0.13.10 [cyanheads/mcp-ts-core#575](https://github.com/cyanheads/mcp-ts-core/issues/575), 0.13.11 [cyanheads/mcp-ts-core#608](https://github.com/cyanheads/mcp-ts-core/issues/608)). Adds `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts`; the image no longer sets `MCP_FORCE_CONSOLE_LOGGING`.
- **Bun 1.4.0 → 1.4.2** — `packageManager`, the Docker base images, and the README badge.
- **`aviation_get_pireps` search log field `level` renamed `flightLevel`** (tool and service logs) — the framework now rewrites a log key named `level`.
- **Station-info debug log no longer records the request URL** — it logs `stationIds`, `hasBbox`, and `state`.
- **`.env.example`** — adds `MCP_REQUEST_STATE_KEY`, `LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`, and the per-signal `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT`, `OTEL_EXPORTER_OTLP_METRICS_ENDPOINT`, and `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT`; the `MCP_HTTP_HOST` default comment reads `127.0.0.1`.
- **Ignore files** — `.gitignore` and `.dockerignore` match `.env*` (`.gitignore` keeps `.env.example`, `.env.template`, `.env.sample`; `.dockerignore` adds the two `.mcpregistry_*` token files); `.mcpbignore` adds `/docs/idea.md`, `/logs/`, `/.cache/`, and `/tests/`; the npm `files` list excludes `dist/*.mcpb`.
- **CodeQL workflow runs one job per language** (`actions`, `javascript-typescript`), each uploading under `/language:<language>`.
- **`framework-skills/` and `scripts/` resynced** to the framework release; README MCP SDK badge `^2.0.0 → ^2.2.0`, Bun badge `v1.4.2`.

## Fixed

- **`server.json` npm entries drop the `run start:*` package arguments** and set `runtimeHint` to `npx`; the streamable-http entry sets `MCP_TRANSPORT_TYPE` to `http` (0.13.11, [cyanheads/mcp-ts-core#622](https://github.com/cyanheads/mcp-ts-core/issues/622)).
